# Поиск заметок в Obsidian по заданному запросу, включая обобщение найденной информации с помощью AI-агента
(Obsidian — это мощное, бесплатное приложение для создания заметок)

## Особенности

- **Интерактивный режим**: Запрос можно вводить после запуска программы
- **Интеграция с AI**: Опциональная обработка через Ollama или OpenAI AI для суммаризации ответов
- **Текстовый вывод**: Результаты выводятся в удобном для чтения текстовом формате
- **Конфигурация через файл**: Все настройки в отдельном файле конфигурации
- **Поддержка нескольких хранилищ**: Поиск по всем хранилищам Obsidian в директории

## Структура проекта

```
.
├── main.py              # Основной скрипт с интерактивным вводом
├── ai_providers.py      # Классы AI провайдеров (Ollama, OpenAI)
├── models.py            # Модели данных (SearchResult)
├── search.py            # Функции поиска по хранилищам
├── config.py            # Загрузка конфигурации
├── requirements.txt     # Зависимости Python
├── README.md            # Эта документация
└── obsidian_search_config.json  # Пример конфигурации
```

## Конфигурация

Все настройки загружаются из файла конфигурации. 

**`obsidian_search_config.json`** в текущей директории

### Пример файла конфигурации (JSON):

```json
{
  "vaults_path": "/путь_к_хранилищам_obsidian",
  "use_ai": true,
  "ai_provider": "ollama",
  "ollama_host": "localhost",
  "ollama_port": 11434,
  "ollama_model": "llama2",
  "openai_api_key": "sk-...",
  "openai_model": "gpt-3.5-turbo",
  "openai_base_url": "https://api.openai.com/v1"
}
```

### Параметры конфигурации:

- **`vaults_path`**: Путь к директории с хранилищами Obsidian (обязательный параметр)
- **`use_ai`**: Использовать ли AI для обработки результатов (true/false, по умолчанию false)
- **`ai_provider`**: Провайдер AI для использования ("ollama" или "openai", по умолчанию "ollama")

#### Параметры Ollama:
- **`ollama_host`**: Хост Ollama API (по умолчанию "localhost")
- **`ollama_port`**: Порт Ollama API (по умолчанию 11434)
- **`ollama_model`**: Модель Ollama для использования (по умолчанию "llama2")

#### Параметры OpenAI:
- **`openai_api_key`**: API ключ OpenAI (обязательно для провайдера "openai")
- **`openai_model`**: Модель OpenAI для использования (по умолчанию "gpt-3.5-turbo")
- **`openai_base_url`**: Базовый URL OpenAI API (по умолчанию "https://api.openai.com/v1")


## Архитектура


### Модули:
1. **`ai_providers.py`** - абстрактные классы и реализации AI провайдеров
2. **`models.py`** - модели данных (SearchResult)
3. **`search.py`** - функции поиска по хранилищам Obsidian
4. **`config.py`** - загрузка конфигурации из файлов
5. **`main.py`** - основной скрипт


### Примечание
В OLLAMA я использовал локально модель YandexGPT-5-Lite-8B-instruct-GGUF (4.9 GB) на ПК без GPU. Ответы вполне релевантные, хотя формируются долго — около 20 секунд.
GGUF — это специальный формат файлов, созданный для того, чтобы большие языковые модели было удобно и быстро запускать на обычных домашних компьютерах и ноутбуках, а не только на мощных серверах.
